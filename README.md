# MatplotlibUtilities

## Overview

MatplotlibUtilities (`matplotlib_utilities`) wraps common Matplotlib workflows behind `MatplotGraphMaker`: a subplot layout, figure-wide `GraphParameters`, and drawing and axis methods whose options are frozen, typed `*Parameters` dataclasses checked against the Matplotlib signatures they are unpacked into.

| Family | Methods |
| ------ | ------- |
| Series | `plot`, `scatter`, `bar`, `barh`, `step`, `errorbar`, `fill_between`, `stackplot` |
| Distribution | `hist`, `boxplot`, `violinplot`, `hexbin`, `hist2d` |
| Image and grid | `imshow`, `set_colorbar`, `contour`, `contourf`, `pcolormesh`, `imscatter` |
| Proportion | `pie` |
| Vector field | `arrow`, `quiver`, `streamplot` |
| Decoration | `legend`, `line`, `annotate`, `span` |
| Axis | `set_label`, `set_lim`, `set_ticks`, `invert`, `set_title`, `set_grid`, `set_grid_below`, `delete_axis_label` |

## Installation

```bash
pip install .
```

Git must be available, because the `color` dependency installs from its repository.

## Usage

A single plot needs no layout and no index; every method draws on the first subplot by default:

```python
import numpy as np
from matplotlib_utilities import GraphAxis, MatplotGraphMaker

x = np.linspace(0, 1, 50)
maker = MatplotGraphMaker()
maker.plot(x=x, y=np.sin(x * 10))
maker.set_label(label="x", axis=GraphAxis.X)
maker.finalize(save_path="sin.png")
```

With several subplots, pass the subplot number (row-major, from 0) as `index`:

```python
from matplotlib_utilities import (
    ColorMap,
    GraphLayout,
    GraphParameters,
    LegendParameters,
    MatplotGraphMaker,
    ScatterParameters,
)

maker = MatplotGraphMaker(
    layout=GraphLayout.from_row_column(row=1, column=2),
    parameters=GraphParameters(figsize=(8, 3)),
)
maker.plot(x=x, y=np.sin(x * 10), index=0)
maker.scatter(
    x=x,
    y=np.sin(x * 10),
    index=1,
    subparams=ScatterParameters(c=np.cos(x * 10), cmap=ColorMap.VIRIDIS, label="sin"),
)
maker.legend(index=1, subparams=LegendParameters(edgecolor="black"))
maker.finalize()
```

Draw Japanese labels with a bundled font:

```python
from matplotlib_utilities import FontFamily, GraphParameters, MatplotGraphMaker

maker = MatplotGraphMaker(parameters=GraphParameters(font_family=FontFamily.JAPANESE))
```
