# parameters

## Overview

Frozen parameter dataclasses for the axis helpers, unpacked into Matplotlib through `to_dict`.

## Components

| Path | Description |
| ---- | ----------- |
| [`grid.py`](./grid.py) | `GridParameters` — `matplotlib.axes.Axes.grid` |
| [`tick_params.py`](./tick_params.py) | `TickParamsParameters` — configuring tick marks and labels on matplotlib axes |
