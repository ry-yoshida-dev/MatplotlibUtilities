# types

## Overview

Shared NumPy array type aliases for stricter static checking than bare `np.ndarray`.

## Components

| Path | Description |
| ---- | ----------- |
| [`numeric_array.py`](./numeric_array.py) | `NumericArray` — integer or floating plot/image data |
| [`subplot_axes_array.py`](./subplot_axes_array.py) | `SubplotAxesArray` — 2D object array of `Axes` from `subplots(squeeze=False)` |
