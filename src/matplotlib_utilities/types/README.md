# types

## Overview

Shared type aliases for stricter static checking than bare `np.ndarray`.

## Components

| Path | Description |
| ---- | ----------- |
| [`numeric_array.py`](./numeric_array.py) | `NumericArray` — integer or floating plot/image data |
| [`subplot_axes_grid.py`](./subplot_axes_grid.py) | `SubplotAxesGrid` — rows of `Axes`, indexed as `grid[row][column]` |
